Convention, not a live name record

Vaults

A useful product: encrypt a file with a seed, anchor only a commitment, bind that commitment to a .kas name as a text record. File bytes never go on-chain. No live KNS name has this binding in the official profile API. Do not look up kns.kas and expect a vault.

What exists

CLI at C:\Users\Remco\kaspa-data-vault: seal → send (5 min window) → open. AES-256-GCM, BIP39, optional wRPC anchor.

What would make it a name feature

A profile/text inscription vault=<package id> and vaultCommit=<32 bytes>, plus a DataVault covenant if you want a KAS bond on the same window.

What is missing

KNS profile keys do not include vault. Wallets do not resolve it. The Silverscript in this repo is not deployed.
