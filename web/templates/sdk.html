Drop-in resolve

Wallets should hit the official KNS indexer. This SDK is a thin client of this app, which already proxies that indexer and adds pay URI / DID conventions.

import { resolve } from "/static/js/kns.js";
const r = await resolve("kns.kas");
// r.owner, r.payUri, r.kasUri, r.did, r.evidence
GET /api/v1/resolve?q=kns.kas
GET /api/v1/resolve?q=kaspa:q…
GET /api/v1/names?owner=kaspa:q…
POST /api/v1/batch  {"names":["kns.kas","nacho.kas"]}
GET /.well-known/kaspa-name.json?name=kns.kas
GET /api/openapi.json

Web 4.0: GET /agent/kns.kas.json · POST /mcp · GET /api/v1/call/kns.kas (402). Conventions: kas://kns.kas · did:kas:kns.kas.
